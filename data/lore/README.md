# 金庸群侠传 DC 版 - 武侠传说数据说明

## 数据文件

### 1. characters.json - 人物数据
包含金庸小说中的主要角色信息。

**结构说明：**
- `characters`: 主要英雄人物列表
  - 每个人物包含：id, name, title, novels（出现小说）, faction（门派）
  - stats: 游戏属性（hp, mp, attack, defense, agility, intelligence, luck）
  - abilities: 掌握的武功
  - personality_traits: 性格特征
  - relationships: 人物关系（配偶、子女、师父、盟友、敌人）
  - story_arc: 人物故事线

- `antagonists`: 主要反派角色列表
  - 结构与英雄人物相同

**包含人物：**

### 2. martial_arts.json - 武功数据
包含金庸小说中的武功系统信息。

**武功分类：**
- `internal_arts`: 内功心法
- `external_arts`: 外功招式
- `weapon_arts`: 兵器武功
- `lightness_arts`: 轻功

**结构说明：**
每个武功包含：
- id, name, category（分类）, tier（等级 S-SSS）
- description: 描述
- effects: 效果（数值加成）
- prerequisites: 修炼条件（等级、属性、前置武功）
- skill_tree: 技能树分支
- known_by: 掌握者
- novel_source: 来源小说

**等级说明：**
- SSS: 绝世神功（如九阴真经、葵花宝典）
- SS: 顶尖武功（如降龙十八掌、独孤九剑）
- S+: 超强武功
- S: 高级武功
- A+: 中高级武功

- `id`, `name`, `description`, `climate`, `culture`
- `major_locations`: 主要地点
- `connections`: 连接区域

locations（具体地点）：
- `id`, `name`, `region`, `faction`, `description`
- `points_of_interest`: 景点

- `famous_residents`: 著名居民
- `key_events`: 关键事件
- `level_range`: 等级范围
