# 嘉兴城方案总结与状态（2D城镇版）

## 1. 目标与范围
本轮针对“嘉兴城”先做一版可玩的 2D RPG 城镇样板，目标如下：

1. 进入嘉兴后，采用城内地图视图（而非仅列表页）。
2. 玩家可用键盘移动主角（WASD/方向键）。
3. 玩家可与 NPC、地标进行近距离互动（E 键）。
4. 引入与金庸嘉兴语境相关的任务与事件雏形。
5. 先落地嘉兴，其他城镇后续再扩展。

## 2. 嘉兴城设计方案（确认稿）
### 2.1 区域与地标（嘉兴）
1. 客栈区：悦来客栈（店小二）。
2. 商街区：河街集市（商人）。
3. 文化区：茶楼书棚（说书人）。
4. 治安区：巡捕岗亭（巡街捕快）。
5. 水岸区：乌篷船埠（南湖船夫）、烟雨楼远眺。
6. 旧迹区：铁枪庙旧址。
7. 探索区：小蓬莱石坊。

### 2.2 交互规则
1. 移动：WASD / 方向键。
2. 互动：靠近目标后按 E。
3. NPC 交互：优先处理可接/可交任务，再进入对话。
4. 地标交互：触发文本事件，部分地标有一次性奖励/标记。

### 2.3 嘉兴任务包（首版）
1. 月河市井风波（巡街捕快）。
2. 南湖夜渡（南湖船夫）。
3. 醉仙楼旧约（说书人）。
4. 药铺急诊（月河郎中）。

## 4. 当前未完成（待迭代）
1. 碰撞系统：建筑/水域尚未做硬碰撞，当前为边界限制。
2. 昼夜系统：尚未启用“夜间专属事件/NPC”切换。
3. 店铺功能深度：嘉兴新增 NPC 仍以任务/对话为主，专属商店逻辑未细化。
4. 主线串联：嘉兴任务已可用，但尚未形成完整章节化引导链。
5. 演出与反馈：缺少特效层（脚步、交互高亮动画、事件过场）。

## 5. 下一步建议（V2）
1. 加入基础碰撞网格（不可穿越区域 + 可行走路网）。
2. 做昼夜切换与夜间事件（码头/小蓬莱）启用逻辑。
3. 把嘉兴任务串为“主线+支线”引导序列（任务日志提示更清晰）。
4. 为嘉兴专属 NPC 增加更明确的店铺/服务功能入口。
5. 在稳定后按同模板扩展到临安、襄阳、少林。
